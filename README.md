# TODO App

Простое консольное приложение для управления задачами.

## Описание

Проект представляет собой минималистичное To-Do приложение, реализованное на Python.  
Позволяет добавлять, просматривать и удалять задачи через консольный интерфейс.

## Возможности

- Добавление задач
- Просмотр списка задач
- Удаление задач
